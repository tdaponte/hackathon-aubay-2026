COMMENT DÉMARRER:

1️⃣  Terminal 1 - App Streamlit
   cd streamlit-simple-form-app
   pip install -r requirements.txt
   streamlit run app.py
   ➜ http://localhost:8501

2️⃣  Terminal 2 - Serveur Webhook
   pip install -r requirements-webhook.txt
   python webhook_server.py
   ➜ http://localhost:8502

3️⃣  Terminal 3 - Tests (optionnel)
   python test_send_field.py
   (envoie des champs de test automatiquement)

============================================================================

POUR TESTER SANS L'AUTRE APP:

$ python test_send_field.py

Ça envoie automatiquement:
→ Champ texte "Quel est votre nom ?"
→ Attends 5 sec
→ Champ date "Quelle est votre date de naissance ?"

Regardez Streamlit pour voir les champs s'afficher!
